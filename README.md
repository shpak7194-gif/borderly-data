# Borderly visa data

Файлы для удалённого обновления визовой базы Borderly.

- `version.json` — маленький файл, который приложение проверяет раз в 24 часа.
- `visa_requirements.json` — полная визовая база.
- `validate_visa_data.mjs` — проверка полной матрицы из 199 паспортов и
  защищённых официальных правил.

## Как выпустить обновление вручную

1. Изменить `visa_requirements.json`.
2. Проверить JSON валидатором Borderly.
3. Увеличить `version` в `version.json` на 1.
4. Обновить поле `updated`.
5. Загрузить оба файла в репозиторий.

Приложение скачает новый `visa_requirements.json` только если `version`
стал больше локальной версии.

Не удаляйте старую рабочую базу до проверки новой.

## Покрытие матрицы

Генератор синхронизирует полный текущий каталог Passport Index: 199
паспортных юрисдикций. При появлении поддерживаемой юрисдикции он создаёт и
новую строку паспорта, и недостающие столбцы направлений. Обычные обновления
правил, структурное расширение матрицы и официальные специальные проверки
учитываются раздельно, поэтому безопасный лимит массовых изменений не мешает
контролируемому расширению базы.

Специальные проверки из `official_entry_watches.json`,
`special_mobility_watches.json` и отдельная проверка Гренландии имеют приоритет
над общим источником. Если официальный сайт временно недоступен или результат
нельзя уверенно распознать, последнее подтверждённое правило сохраняется.
