# Borderly entry guides

Персональные практические гайды `паспорт -> страна`.

## Как обновить без нового APK

1. Изменить `entry_guides.json`.
2. Увеличить поле `version` внутри `entry_guides.json`.
3. Поставить то же число в `entry_guides_version.json`.
4. Запустить `node validate_entry_guides.mjs`.
5. Загрузить файлы в корень `borderly-data`.

Приложение проверяет новую версию не чаще одного раза в 24 часа, полностью валидирует JSON до замены кэша и при ошибке оставляет последнюю рабочую базу.

Не используйте ссылки посредников. Для `links` добавляйте только HTTPS-ссылки на официальный государственный ресурс; ровно одна ссылка должна иметь `primary: true`.
